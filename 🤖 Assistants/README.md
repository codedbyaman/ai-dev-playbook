# AI Assistants

Reusable instruction files for popular AI coding assistants.

Each guide is tailored to the strengths, workflow, and limitations of a specific AI assistant while following the same engineering principles:

- Correctness over speed
- Minimal, maintainable changes
- Respect existing codebases
- Verify before completion

---

## Available Assistants

| Assistant | Description |
|-----------|-------------|
| **CLAUDE.md** | Engineering-focused behavioral guidelines for Claude Code. Emphasizes reasoning, minimal diffs, careful planning, and high-quality implementation. |
| **CHATGPT.md** | Best practices for using ChatGPT as a development, debugging, testing, documentation, and architecture assistant. |
| **GEMINI.md** | Guidance for using Google Gemini on software engineering, code understanding, documentation, and large-context analysis. |
| **CURSOR.md** | Workflow optimized for Cursor IDE with incremental editing, project awareness, and context-driven code generation. |
| **COPILOT.md** | Guidelines for GitHub Copilot focused on inline code completion, boilerplate generation, and context-aware suggestions. |

---

## Philosophy

Regardless of the assistant being used, every guide encourages:

- Understanding existing code before making changes
- Making the smallest possible modification
- Reusing existing implementations
- Following project conventions
- Avoiding unnecessary abstractions
- Verifying changes before considering work complete

---

## Recommended Usage

Choose the guide that matches your AI assistant and include it in your project.

Examples:

```
CLAUDE.md
CHATGPT.md
GEMINI.md
CURSOR.md
COPILOT.md
```

These files can be customized further for specific languages, frameworks, or repositories.
