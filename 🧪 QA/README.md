# QA Playbooks

Practical AI playbooks for Quality Assurance engineers.

This section helps AI assistants support manual testing, automation, API validation, mobile testing, accessibility, bug investigation, and test design using proven QA practices.

The goal is not simply to generate test cases or automation code, but to help engineers build reliable, maintainable, and high-quality software.

| Playbook | Description |

---

## Philosophy

Every QA playbook follows the same principles:

- Understand the feature before testing.
- Focus on risk-based testing.
- Prefer reproducible defects.
- Minimize flaky automation.
- Write maintainable test cases.
- Verify results using evidence.
- Preserve existing application behavior.
