# AI Dev Playbook

> Practical AI workflows, prompts, and engineering guidelines for building high-quality software.

AI coding assistants are becoming part of every developer's workflow. This repository focuses on helping engineers collaborate effectively with AI rather than simply collecting prompts.

Instead of replacing engineering judgment, these playbooks teach AI assistants to:

- Understand existing code before making changes
- Make minimal, maintainable modifications
- Follow project conventions
- Verify work before completion
- Explain assumptions and tradeoffs
- Write production-ready code

## Philosophy

Good software comes from good engineering decisions.

AI should amplify those decisions, not replace them.

The goal of this repository is to help developers use AI to write cleaner, safer, and more maintainable code.
